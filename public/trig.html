📌 سوال شماره ۱
✓ گزینه ۱ صحیح است
اگر $a \in \mathbb{R}$ و $a eq 0$ و داشته باشیم $a \cos x = 1 + \sin x$، آنگاه حاصل $ rac{1}{\cos x}$ کدام است؟
1) $\frac{1+a^2}{2a}$
2) $\frac{1+a^2}{2}$
3) $\frac{1+a^2}{a}$
4) $\frac{1+a}{2a}$
💡 راه حل تشریحی و مفهومی:
گام اول: تقسیم طرفین بر $\cos x$ معادله داده‌شده رو به کسینوس تقسیم می‌کنیم تا پای تانژانت به معادله باز بشه:
$$a = \frac{1 + \sin x}{\cos x} = \frac{1}{\cos x} + \tan x \quad (1)$$
گام دوم: استفاده از اتحاد مزدوج طلایی از کتاب ریاضی دهم می‌دونیم $1 + \tan^2 x = \frac{1}{\cos^2 x}$، پس تفاضلشون یک میشه:
$$\frac{1}{\cos^2 x} - \tan^2 x = 1$$
حالا اتحاد مزدوج رو باز می‌کنیم:
$$\left(\frac{1}{\cos x} + \tan x\right)\left(\frac{1}{\cos x} - \tan x\right) = 1$$
پرانتز اول دقیقاً همون $a$ است! پس:
$$a \cdot \left(\frac{1}{\cos x} - \tan x\right) = 1 \implies \frac{1}{\cos x} - \tan x = \frac{1}{a} \quad (2)$$
گام سوم: جمع دو رابطه و حذف $\tan x$ کافیه معادله (۱) و (۲) رو با هم جمع بزنیم:
$$2 \left(\frac{1}{\cos x}\right) = a + \frac{1}{a} = \frac{a^2 + 1}{a} \implies \frac{1}{\cos x} = \frac{1 + a^2}{2a}$$
📌 سوال شماره ۲
✓ گزینه ۱ صحیح است
اگر $3 \sin \alpha + 2 \cos \alpha = 1$ باشد، حاصل $8 \tan \alpha + 3 \cot \alpha$ کدام است؟
1) $-12$
2) $-6$
3) $-8$
4) $-16$
💡 راه حل تشریحی و مفهومی:
گام اول: تبدیل عبارت خواسته به تانژانت چون $\cot \alpha = \frac{1}{\tan \alpha}$ است:
$$8 \tan \alpha + 3 \cot \alpha = 8 \tan \alpha + \frac{3}{\tan \alpha} = \frac{8 \tan^2 \alpha + 3}{\tan \alpha}$$
پس فقط کافیه مقدار صورت یعنی $8 \tan^2 \alpha + 3$ رو پیدا کنیم!
گام دوم: تقسیم بر $\cos \alpha$ و به توان دو رساندن معادله فرض رو به $\cos \alpha$ تقسیم می‌کنیم:
$$3 \tan \alpha + 2 = \frac{1}{\cos \alpha}$$
حالا هر دو طرف رو به توان ۲ می‌رسونیم:
$$(3 \tan \alpha + 2)^2 = \frac{1}{\cos^2 \alpha}$$
چون $\frac{1}{\cos^2 \alpha} = 1 + \tan^2 \alpha$ است، بسط مربع دوجمله‌ای رو می‌نویسیم:
$$9 \tan^2 \alpha + 12 \tan \alpha + 4 = 1 + \tan^2 \alpha$$
مرتب می‌کنیم:
$$8 \tan^2 \alpha + 12 \tan \alpha + 3 = 0 \implies 8 \tan^2 \alpha + 3 = -12 \tan \alpha$$
گام سوم: جایگذاری نهایی مقدار به دست اومده رو می‌ذاریم توی کسر خواستهٔ سوال:
$$\frac{8 \tan^2 \alpha + 3}{\tan \alpha} = \frac{-12 \tan \alpha}{\tan \alpha} = -12$$
📌 سوال شماره ۳
✓ گزینه ۴ صحیح است
اگر $\tan \alpha + \cot \alpha = \frac{8}{5}$ و $0^\circ < \alpha < 90^\circ$ باشد، حاصل $\sin^3 \alpha + \cos^3 \alpha$ چقدر است؟
1) $\frac{3}{4}$
2) $\frac{3}{8}$
3) $\frac{9}{8}$
4) $\frac{9}{16}$
💡 راه حل تشریحی و مفهومی:
گام اول: پیدا کردن ضرب سینوس در کسینوس
$$\tan \alpha + \cot \alpha = \frac{\sin \alpha}{\cos \alpha} + \frac{\cos \alpha}{\sin \alpha} = \frac{\sin^2 \alpha + \cos^2 \alpha}{\sin \alpha \cos \alpha} = \frac{1}{\sin \alpha \cos \alpha} = \frac{8}{5} \implies \sin \alpha \cos \alpha = \frac{5}{8}$$
گام دوم: پیدا کردن مجموع $(\sin \alpha + \cos \alpha)$
$$(\sin \alpha + \cos \alpha)^2 = 1 + 2 \sin \alpha \cos \alpha = 1 + 2\left(\frac{5}{8}\right) = 1 + \frac{5}{4} = \frac{9}{4}$$
چون در ربع اول هستیم و سینوس و کسینوس مثبتند:
$$\sin \alpha + \cos \alpha = \sqrt{\frac{9}{4}} = \frac{3}{2}$$
گام سوم: اتحاد مجموع مکعبات (چاق و لاغر)
$$\sin^3 \alpha + \cos^3 \alpha = (\sin \alpha + \cos \alpha)(1 - \sin \alpha \cos \alpha)$$
$$= \frac{3}{2} \times \left(1 - \frac{5}{8}\right) = \frac{3}{2} \times \frac{3}{8} = \frac{9}{16}$$
📌 سوال شماره ۴
✓ گزینه ۴ صحیح است
اگر $\sin x = \frac{a^4 + 1}{2a^2}$ باشد، آنگاه $\cos x$ برابر است با:
1) $\frac{a^2+1}{2a^2}$
2) $\pm \frac{a^2+1}{2a^2}$
3) $1$
4) صفر
💡 راه حل تشریحی و مفهومی:
گام اول: تحلیل دامنه عبارت سینوس کسر داده‌شده رو تفکیک می‌کنیم:
$$\sin x = \frac{a^4}{2a^2} + \frac{1}{2a^2} = \frac{1}{2}\left(a^2 + \frac{1}{a^2}\right)$$
می‌دانیم برای هر عدد حقیقی غیرصفر $a$:
$$\left(a - \frac{1}{a}\right)^2 \ge 0 \implies a^2 + \frac{1}{a^2} \ge 2$$
بنابراین همیشه داریم: $\sin x \ge \frac{1}{2}(2) = 1$.
گام دوم: تطابق با دایره مثلثاتی در دایره مثلثاتی سینوس زاویه نمی‌تونه بیشتر از ۱ بشه ($\sin x \le 1$). تنها حالتی که هر دو نامساوی برقرار باشن اینه که دقیقاً:
$$\sin x = 1 \quad (\text{به ازای } a = \pm 1)$$
گام سوم: محاسبه کسینوس وقتی سینوس برابر ۱ است:
$$\cos^2 x = 1 - \sin^2 x = 1 - 1 = 0 \implies \cos x = 0$$
📌 سوال شماره ۵
✓ گزینه ۱ صحیح است
اگر $\sin x + \cos x = \frac{1}{2}$ باشد، حاصل $\sin^3 x + \cos^3 x$ کدام است؟
1) $\frac{11}{16}$
2) $-\frac{1}{8}$
3) $\frac{11}{8}$
4) $\frac{7}{8}$
💡 راه حل تشریحی و مفهومی:
گام اول: به توان ۲ رساندن برای یافتن ضرب
$$(\sin x + \cos x)^2 = \left(\frac{1}{2}\right)^2 = \frac{1}{4}$$
$$1 + 2 \sin x \cos x = \frac{1}{4} \implies 2 \sin x \cos x = -\frac{3}{4} \implies \sin x \cos x = -\frac{3}{8}$$
گام دوم: تجزیه اتحاد مکعبات
$$\sin^3 x + \cos^3 x = (\sin x + \cos x)(1 - \sin x \cos x)$$
$$= \frac{1}{2} \times \left[1 - \left(-\frac{3}{8}\right)\right] = \frac{1}{2} \times \frac{11}{8} = \frac{11}{16}$$
📌 سوال شماره ۶
✓ گزینه ۴ صحیح است
اگر $\tan \alpha = \frac{12}{5}$ و $\alpha$ در ناحیه سوم باشد، حاصل $12 \cot \alpha + 13 \cos \alpha$ چقدر است؟
1) $1$
2) $-3$
3) $14$
4) صفر
💡 راه حل تشریحی و مفهومی:
گام اول: محاسبه کتانژانت
$$\cot \alpha = \frac{1}{\tan \alpha} = \frac{5}{12} \implies 12 \cot \alpha = 12 \times \frac{5}{12} = 5$$
گام دوم: محاسبه کسینوس در ربع سوم
$$1 + \tan^2 \alpha = \frac{1}{\cos^2 \alpha} \implies 1 + \frac{144}{25} = \frac{169}{25} = \frac{1}{\cos^2 \alpha} \implies \cos^2 \alpha = \frac{25}{169}$$
⚠️
دام تستی: زاویه $\alpha$ در ناحیه سوم قرار دارد و در ربع سوم کسینوس منفی است: $$\cos \alpha = -\sqrt{\frac{25}{169}} = -\frac{5}{13} \implies 13 \cos \alpha = -5$$
گام سوم: جمع دو بخش
$$12 \cot \alpha + 13 \cos \alpha = 5 + (-5) = 0$$
📌 سوال شماره ۷
✓ گزینه ۴ صحیح است
ساده شدهٔ عبارت $(1 - \sin^2 \theta)\left(1 + \frac{1}{\cos^2 \theta}\right) - (1 - \cos \theta)^2$ کدام است؟
1) $\sin^2 \theta$
2) $\cos^2 \theta$
3) $-\cos^2 \theta$
4) $2 \cos \theta$
💡 راه حل تشریحی و مفهومی:
گام اول: ساده‌سازی بخش ضرب اول می‌دانیم $1 - \sin^2 \theta = \cos^2 \theta$، پس:
$$\cos^2 \theta \left(1 + \frac{1}{\cos^2 \theta}\right) = \cos^2 \theta + \cos^2 \theta \cdot \frac{1}{\cos^2 \theta} = \cos^2 \theta + 1$$
گام دوم: باز کردن مربع دوجمله‌ای دوم
$$(1 - \cos \theta)^2 = 1 - 2 \cos \theta + \cos^2 \theta$$
گام سوم: تفریق دو عبارت
$$(\cos^2 \theta + 1) - (1 - 2 \cos \theta + \cos^2 \theta)$$
$$= \cos^2 \theta + 1 - 1 + 2 \cos \theta - \cos^2 \theta = 2 \cos \theta$$
📌 سوال شماره ۸
✓ گزینه ۳ صحیح است
بیشترین مقدار $A = \sin^2 x + \sin x + 3$ چقدر از کمترین مقدارش بیشتر است؟
1) $5$
2) $\frac{11}{4}$
3) $\frac{9}{4}$
4) $\frac{3}{4}$
💡 راه حل تشریحی و مفهومی:
گام اول: تغییر متغیر و تشکیل تابع درجه ۲ فرض می‌کنیم $t = \sin x$، با شرط $-1 \le t \le 1$:
$$A(t) = t^2 + t + 3$$
با روش مربع کامل کردن:
$$A(t) = \left(t + \frac{1}{2}\right)^2 + 3 - \frac{1}{4} = \left(t + \frac{1}{2}\right)^2 + \frac{11}{4}$$
گام دوم: تعیین کمترین مقدار (مینیمم) چون ضریب $t^2$ مثبت است، رأس سهمی در $t = -\frac{1}{2}$ است که دقیقاً داخل بازه $[-1, 1]$ است:
$$A_{\min} = \frac{11}{4}$$
گام سوم: تعیین بیشترین مقدار (ماکزیمم) ماکزیمم در دورترین نقطه مرزی نسبت به رأس رخ می‌دهد ($t = 1$):
$$A_{\max} = A(1) = 1^2 + 1 + 3 = 5$$
گام چهارم: محاسبه اختلاف خواسته شده
$$A_{\max} - A_{\min} = 5 - \frac{11}{4} = \frac{20 - 11}{4} = \frac{9}{4}$$
📌 سوال شماره ۹
✓ گزینه ۴ صحیح است
اگر $\sin \alpha + \cos \alpha = \frac{1}{4}$ باشد، حاصل $|\sin \alpha - \cos \alpha|$ چقدر است؟
1) $\frac{\sqrt{31}}{16}$
2) $\frac{\sqrt{33}}{4}$
3) $\frac{\sqrt{29}}{4}$
4) $\frac{\sqrt{31}}{4}$
💡 راه حل تشریحی و مفهومی:
گام اول: به توان ۲ رساندن تفاضل فرض می‌کنیم $D = |\sin \alpha - \cos \alpha|$:
$$D^2 = (\sin \alpha - \cos \alpha)^2 = \sin^2 \alpha + \cos^2 \alpha - 2 \sin \alpha \cos \alpha = 1 - 2 \sin \alpha \cos \alpha$$
گام دوم: استخراج $2 \sin \alpha \cos \alpha$ از جمع
$$(\sin \alpha + \cos \alpha)^2 = \left(\frac{1}{4}\right)^2 = \frac{1}{16}$$
$$1 + 2 \sin \alpha \cos \alpha = \frac{1}{16} \implies 2 \sin \alpha \cos \alpha = \frac{1}{16} - 1 = -\frac{15}{16}$$
گام سوم: جایگذاری در $D^2$ و جذر گرفتن
$$D^2 = 1 - \left(-\frac{15}{16}\right) = 1 + \frac{15}{16} = \frac{31}{16} \implies D = \sqrt{\frac{31}{16}} = \frac{\sqrt{31}}{4}$$
📌 سوال شماره ۱۰
✓ گزینه ۲ صحیح است
اگر $\frac{\sin^2 x - 2 \cos^2 x + 1}{\sin^2 x + 2 \cos^2 x - 1} = 3$ باشد، مقدار $\tan^2 x$ چقدر است؟
1) $1$
2) $2$
3) $3$
4) $4$
💡 راه حل تشریحی و مفهومی:
گام اول: جایگزینی عدد ۱ با $\sin^2 x + \cos^2 x$ صورت کسر:
$$\sin^2 x - 2 \cos^2 x + (\sin^2 x + \cos^2 x) = 2 \sin^2 x - \cos^2 x$$
مخرج کسر:
$$\sin^2 x + 2 \cos^2 x - (\sin^2 x + \cos^2 x) = \cos^2 x$$
گام دوم: تفکیک کسر به تانژانت
$$\frac{2 \sin^2 x - \cos^2 x}{\cos^2 x} = \frac{2 \sin^2 x}{\cos^2 x} - \frac{\cos^2 x}{\cos^2 x} = 2 \tan^2 x - 1$$
گام سوم: حل معادله ساده
$$2 \tan^2 x - 1 = 3 \implies 2 \tan^2 x = 4 \implies \tan^2 x = 2$$
📌 سوال شماره ۱۱
✓ گزینه ۲ صحیح است
اگر $\sin^6 \alpha + \sin^4 \alpha + \cos^6 \alpha + \cos^4 \alpha = A + B \sin^2 \alpha \cos^2 \alpha$ باشد، حاصل $A + B$ کدام است؟
1) $-7$
2) $-3$
3) $3$
4) $7$
💡 راه حل تشریحی و مفهومی:
گام اول: دسته‌بندی توان‌های ۴ و ۶
$$(\sin^4 \alpha + \cos^4 \alpha) + (\sin^6 \alpha + \cos^6 \alpha)$$
گام دوم: استفاده از اتحادهای کمکی فرعی دهم می‌دانیم:
$$\sin^4 \alpha + \cos^4 \alpha = (\sin^2 \alpha + \cos^2 \alpha)^2 - 2 \sin^2 \alpha \cos^2 \alpha = 1 - 2 \sin^2 \alpha \cos^2 \alpha$$
$$\sin^6 \alpha + \cos^6 \alpha = (\sin^2 \alpha + \cos^2 \alpha)^3 - 3 \sin^2 \alpha \cos^2 \alpha (\sin^2 \alpha + \cos^2 \alpha) = 1 - 3 \sin^2 \alpha \cos^2 \alpha$$
گام سوم: جمع دو عبارت و تطبیق ضرایب
$$(1 - 2 \sin^2 \alpha \cos^2 \alpha) + (1 - 3 \sin^2 \alpha \cos^2 \alpha) = 2 - 5 \sin^2 \alpha \cos^2 \alpha$$
مقایسه با $A + B \sin^2 \alpha \cos^2 \alpha$:
$$A = 2 ,\quad B = -5 \implies A + B = 2 + (-5) = -3$$
📌 سوال شماره ۱۲
✓ گزینه ۱ صحیح است
اگر $x$ زاویه‌ای در ربع چهارم باشد، حاصل عبارت $(4 \sin^2 60^\circ - 3 \sin^2 x) \sqrt[4]{\tan^4 x + 2 \tan^2 x + 1}$ با کدام گزینه برابر است؟
1) $3 \cos x$
2) $-3 \cos x$
3) $3 \cot x \cos x$
4) $-3 \cot x \cos x$
💡 راه حل تشریحی و مفهومی:
گام اول: ساده‌سازی پرانتز اول می‌دانیم $\sin 60^\circ = \frac{\sqrt{3}}{2} \implies \sin^2 60^\circ = \frac{3}{4}$:
$$4 \sin^2 60^\circ - 3 \sin^2 x = 4\left(\frac{3}{4}\right) - 3 \sin^2 x = 3 - 3 \sin^2 x = 3(1 - \sin^2 x) = 3 \cos^2 x$$
گام دوم: ساده‌سازی عبارت زیر رادیکال فرجه ۴ زیر رادیکال اتحاد مربع کامل است:
$$\tan^4 x + 2 \tan^2 x + 1 = (\tan^2 x + 1)^2 = \left(\frac{1}{\cos^2 x}\right)^2 = \frac{1}{\cos^4 x}$$
ریشه چهارم می‌گیریم:
$$\sqrt[4]{\frac{1}{\cos^4 x}} = \frac{1}{|\cos x|}$$
⚠️
دام تستی بسیار مهم: زاویه $x$ در ربع چهارم است. در ربع چهارم، محور کسینوس‌ها مثبت است ($\cos x > 0$)، بنابراین قدر مطلق بدون تغییر باز می‌شود:
$$|\cos x| = \cos x \implies \frac{1}{|\cos x|} = \frac{1}{\cos x}$$
گام سوم: ضرب دو عبارت
$$3 \cos^2 x \times \frac{1}{\cos x} = 3 \cos x$$
